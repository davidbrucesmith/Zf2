# ZF1 Magic Flute Source Library

Use this directory for source corpus materials and source-rooted transformation analyses.

## Subdirectories

- originals/: direct source artifacts (scores, libretti, manuscripts, symbolic files, media).
- transformations/: analysis and transformation records derived from ZF1 sources.
- metadata/: markdown metadata notes for assets and batches.

## Rule

Every asset should have:

1. an Asset ID,
2. a catalog row in materials/catalogs/asset_catalog.csv,
3. a nearby metadata note in metadata/ or originals/analysis/.
