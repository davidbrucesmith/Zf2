# ZF2 Sequel Working Library

Use this directory for active ZF2 composition assets, analyses, and exports.

## Subdirectories

- sketches/: rough compositional studies.
- sections/: section-scoped working packages.
- stems/: stem assets used in recovery or orchestration.
- notation/: Dorico, MusicXML, and PDF notation outputs.
- midi/: MIDI working files.
- audio/: audio renders and references.
- video/: video references and sync tests.
- analysis/: transformation and dramaturgical analysis docs.
- exports/: deliverables prepared for external review.
- metadata/: markdown metadata notes for ZF2 assets.

## Rule

Track every major asset in materials/catalogs/asset_catalog.csv and link it to section IDs in materials/catalogs/section_catalog.csv.
