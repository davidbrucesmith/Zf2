#### Technical Note: Melodyne Sensitivity and Spurious Note Suppression

Current baseline: all extractions so far (R02, R03, R04) use Melodyne's default automatic note-separation behavior with no manual sensitivity adjustment. The blob splitting seen is out-of-the-box detection, not a tuned pass — so there is real room to test whether adjusting sensitivity reduces spurious notes before resorting to post-export cleanup.

Melodyne's blob-detection threshold is adjustable per algorithm. Two approaches to reduce vibrato/nuance-driven spurious notes:

1. **Note Separation / detection threshold**: In the Algorithm settings (or via the Macro/blob-editing tools), Melodyne exposes a note-separation sensitivity that controls how readily closely-spaced pitch fluctuations are split into separate note blobs. Lowering sensitivity merges rapid micro-fluctuations (vibrato, portamento) into a single sustained blob rather than fragmenting them.
2. **Velocity-based filtering (post-export)**: this hypothesis is testable. Vibrato- and nuance-driven notes plausibly correlate with low velocity/amplitude relative to the surrounding sustained note, since they are transient deviations rather than deliberate attacks. A practical test: export raw MIDI, then in DP filter/select notes below a velocity threshold (e.g. bottom 15-20% of the track's velocity range) and inspect whether they cluster at the same pitch/time as the suspected spurious notes. If confirmed, a velocity floor could be used as a fast first-pass cleanup filter before manual correction.

Both approaches should be tested against a single stem before applying broadly, since over-suppression risks losing genuine short ornamental notes (e.g. grace notes, trills) that also sit at low velocity.

**Resolved — sensitivity control confirmed (Celemony Note Assignment Mode documentation):**

Melodyne provides a dedicated **Note Assignment Mode** (separate mode, own toolbox) with a two-part slider next to the toolbox, available specifically for **polyphonic algorithms** (Polyphonic Sustain / Polyphonic Decay):

- **Parenthesis (right indicator):** controls how many "potential notes" (hollow/silhouette blobs — pitches Melodyne considered but didn't commit to as active notes) are displayed.
- **Ball (left indicator):** controls the probability threshold for promoting a potential note to an active (solid) note. Moving the Ball left reduces the number of active notes generated from potentials — this is the direct lever for suppressing vibrato/nuance-driven spurious notes without deleting the underlying detection (they remain visible as inactive potentials, individually reactivatable).

Also relevant:
- **Venetian Blinds** (Note Assignment Mode, polyphonic only): restrict the pitch range within which Melodyne assigns notes, auto-deactivating notes outside the range — useful for excluding implausible register content (e.g. spurious high overtones on a low stem).
- **"Separate Notes as Trill"** (Melodic algorithm only, via Note Separation Tool context menu): the inverse operation — deliberately slices a vibrato passage into discrete notes at each pitch peak/valley. Relevant if a given vibrato is compositionally meaningful rather than noise to be suppressed.
- **Energy Share Tool** (Polyphonic Sustain/Decay only): redistributes shared overtone energy between simultaneously-sounding notes — relevant for tone-color balance in chords, not directly for spurious-note suppression.

Applied plan: use the duplicate-track approach (Melodic vs. Polyphonic Sustain) as already adopted, and on the Polyphonic Sustain duplicate specifically, enter Note Assignment Mode and adjust the Ball indicator leftward to reduce spurious active notes in duet/harmony passages before final export.

## Pilot Transition Note (2026-08-22)

R07 is expected to be the last extraction run within the scope of this pilot (S01.03 — Melodyne Stem Feasibility). Once R07 is complete and logged, the immediate next phase of work moves beyond stem-level Melodyne extraction into passage-level compositional assembly. This next phase is a distinct scope, likely warranting its own experiment (tentatively S01.04) and possibly its own D-doc, and covers:
