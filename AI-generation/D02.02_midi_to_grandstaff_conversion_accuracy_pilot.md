# D02.02 MIDI-to-Grandstaff Conversion Accuracy Pilot

Document Status: Draft v0.1  
Date: 2026-07-30  
Parent: D02.00 XML/MIDI Conversion Reliability Master Plan

## 1. Purpose
This pilot evaluates whether convert_midi_to_grandstaff_xml.py produces structurally correct and musically useful grand-staff MusicXML from representative MIDI inputs.

The emphasis is conversion validity, staff assignment behavior, and alignment integrity.

## 2. Script Under Test
Primary executable:

1. music-transformer/convert_midi_to_grandstaff_xml.py

## 3. Questions
This pilot asks:

1. Does conversion complete successfully for representative files?
2. Is generated MusicXML structurally valid for downstream notation tools?
3. Are RH/LH assignments musically plausible for the target texture?
4. Do measure boundaries and durations remain coherent?

## 4. Test Corpus
Use at least:

1. one cleaned project MIDI file
2. one dense polyphonic excerpt
3. one simpler control file

Prefer files already used in music-transformer/data/input for reproducibility.

## 5. Procedure

1. Convert each MIDI file using fixed command settings.
2. Open outputs in at least one notation-aware consumer (when available).
3. Inspect measure count, note continuity, and staff distribution.
4. Compare against source MIDI phrase boundaries and cadential points.
5. Record any conversion warnings, dropped events, or invalid output behavior.

## 6. Acceptance Criteria
Pass for a file requires:

1. successful conversion without exception
2. output that loads as valid MusicXML in target toolchain
3. no obvious measure corruption
4. staff assignment that is at least compositionally editable

Pilot pass requires majority pass across corpus and no critical structural corruption.
