# D02.01 Cleanup MIDI Notes Validation Pilot

Document Status: Draft v0.1  
Date: 2026-07-30  
Parent: D02.00 XML/MIDI Conversion Reliability Master Plan

## 1. Purpose
This pilot validates reliability and musical correctness of duplicate/overlap cleanup in cleanup_midi_notes.py.

The focus is event integrity first, musical interpretation second.

## 2. Script Under Test
Primary executable:

1. music-transformer/cleanup_midi_notes.py

Primary module logic:

1. music-transformer/src/midi_cleanup.py

## 3. Questions
This pilot asks:

1. Are true duplicate note-ons removed correctly?
2. Are overlapping same-pitch notes corrected without creating dangling note-offs?
3. Does cleanup preserve valid non-duplicate musical texture?
4. Are outputs deterministic across repeated runs?

## 4. Test Corpus
Use a small fixed corpus with at least:

1. known duplicate-note case
2. known overlap case
3. clean reference file
4. dense real-world segment from active project

Include current repository test assets where applicable.

## 5. Procedure

1. Run baseline cleanup on all corpus files.
2. Compare event counts before and after by channel/pitch.
3. Check note-on/off pairing integrity.
4. Verify no unintended deletion of valid repeated attacks.
5. Repeat same run twice to confirm deterministic output.

## 6. Acceptance Criteria
Pass for a file requires:

1. expected duplicate removals only
2. expected overlap shortening only
3. no orphan note-offs and no unclosed note-ons
4. no crash and no malformed MIDI output

Pilot pass requires all corpus files to satisfy criteria or have clearly documented out-of-scope reasons.
