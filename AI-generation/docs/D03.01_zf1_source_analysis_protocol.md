# D03.01 ZF1 Source Analysis Protocol

Document Status: Draft v0.1  
Date: 2026-08-07  
Parent: D03.00 ZF1 Source and Transformation Corpus Master Plan

## 1. Purpose

Define a consistent analytical method for reading ZF1 source materials so that each analysis can directly support ZF2 transformation design.

## 2. Inputs

Minimum required inputs per analysis record:

1. One source asset ID from materials/catalogs/asset_catalog.csv.
2. Source file in materials/sources/ZF1-magic-flute/originals/.
3. Target ZF2 section ID (or provisional section ID).

## 3. Procedure

1. Identify source passage boundaries (act/scene/measure).
2. Record formal segmentation and phrase boundaries.
3. Extract melodic, bass, and harmonic anchor events.
4. Record orchestration and texture signatures.
5. Identify motifs and dramatic markers.
6. Assess transformability for ZF2 continuation.

## 4. Output Format

Use:

1. materials/templates/source_analysis_template.md

Store completed analyses in:

1. materials/sources/ZF1-magic-flute/originals/analysis/

## 5. Quality Gate

An analysis passes only when it includes:

1. clear source boundary citation,
2. formal and harmonic summary,
3. explicit transformability assessment,
4. at least one linked target section ID.

## 6. Deliverable

One completed markdown analysis per priority source passage, cross-linked in section_catalog.csv.
