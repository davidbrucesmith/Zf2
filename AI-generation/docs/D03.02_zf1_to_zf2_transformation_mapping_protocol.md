# D03.02 ZF1-to-ZF2 Transformation Mapping Protocol

Document Status: Draft v0.1  
Date: 2026-08-07  
Parent: D03.00 ZF1 Source and Transformation Corpus Master Plan

## 1. Purpose

Define how to document transformation logic from ZF1 source material into ZF2 section outputs.

## 2. Inputs

Minimum required inputs per mapping record:

1. One completed D03.01 source analysis.
2. Source asset IDs and section IDs.
3. One or more transformed outputs (notation, MIDI, audio, or mixed media).

## 3. Procedure

1. State dramatic and compositional intent.
2. Enumerate transformation operations in sequence.
3. Capture parameters and constraints per operation.
4. Compare source and result for preserved and altered features.
5. Record validation results for notation/timing/listening coherence.
6. Decide promotion status: draft, accepted, or rejected.

## 4. Output Format

Use:

1. materials/templates/transformation_analysis_template.md

Store completed mappings in:

1. materials/sources/ZF1-magic-flute/transformations/
2. materials/sources/ZF2-sequel/analysis/

## 5. Quality Gate

A mapping passes only when it includes:

1. operation sequence with rationale,
2. explicit source and output asset IDs,
3. comparison notes showing what changed,
4. actionable follow-up or promotion decision.

## 6. Deliverable

One transformation mapping record per major ZF2 section revision cycle.
