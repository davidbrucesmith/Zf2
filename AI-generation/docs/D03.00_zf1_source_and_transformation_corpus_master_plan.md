# D03.00 ZF1 Source and Transformation Corpus Master Plan

Document Status: Draft v0.1  
Date: 2026-08-07  
Role in Program: Parent research document for ZF1 source analysis and ZF2 transformation mapping

## 1. Purpose

This stream formalizes how source materials from Mozart's Die Zauberflote (ZF1) are collected, analyzed, and transformed into ZF2 compositional material.

The goal is to make every major ZF2 section traceable to explicit ZF1 source evidence and documented transformation logic.

## 2. Scope

This stream governs:

1. Source corpus acquisition and verification.
2. Source-level analytical documents.
3. Transformation-analysis documents linked to ZF2 sections.
4. Metadata and provenance logging for all source and derived media.

## 3. Repository Linkage

Primary material storage is under:

1. materials/sources/ZF1-magic-flute/
2. materials/sources/ZF2-sequel/
3. materials/catalogs/asset_catalog.csv
4. materials/catalogs/section_catalog.csv

This document defines research method and quality gates; the materials directory stores artifacts.

## 4. Program Structure

Initial child documents:

1. D03.01 ZF1 source analysis protocol.
2. D03.02 ZF1-to-ZF2 transformation mapping protocol.

Additional D03 child documents may be added for section-specific studies.

## 5. Core Questions

1. Which ZF1 numbers and passages form the primary source backbone for ZF2?
2. What formal, melodic, harmonic, rhythmic, and orchestral features are retained or transformed?
3. How can each ZF2 section be mapped to source passages with clear rationale?
4. Which transformations are musically effective and reproducible?

## 6. Minimum Evidence Standard

A ZF2 section is evidence-complete only if all of the following exist:

1. At least one cited ZF1 source asset in asset catalog.
2. A source analysis record using D03.01 protocol.
3. A transformation mapping record using D03.02 protocol.
4. Section linkage in section_catalog.csv.

## 7. Deliverables

1. Verified ZF1 source corpus index.
2. Section-by-section source analyses.
3. Transformation mapping dossiers per major ZF2 section.
4. Consolidated source-to-sequel traceability table.

## 8. Exit Criteria

D03 enters maintenance when:

1. all planned ZF2 sections have at least one documented ZF1 linkage,
2. all high-priority source assets have provenance metadata,
3. transformation mappings are reproducible enough for revision cycles.
