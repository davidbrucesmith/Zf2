Document Status: Draft v0.1  
Date: 2026-07-30  
Parent: D02.00 XML/MIDI Conversion Reliability Master Plan

## 1. Purpose
This study formalizes regression tests for enforce_piano_strict.py and verifies that the 2x12 attack-span rule behaves consistently across representative material.

The goal is to prevent silent behavioral drift while refining algorithm choices.

## 2. Script Under Test
Primary executable:

1. music-transformer/enforce_piano_strict.py

Primary module logic:

1. music-transformer/src/midi_piano_strict.py

## 3. Questions
This study asks:

1. Are attack-time note sets reduced according to the intended 2x12 rule?
2. Are sustained notes correctly excluded from attack-set evaluation?
3. Does pruning preserve musically salient outer structure when possible?
4. Is output deterministic and free of note-on/off mismatches?

## 4. Regression Corpus Design
Define files that cover:

1. sparse piano textures
2. dense attack clusters
3. sustained-pedal scenarios
4. octave doublings and close-interval stacks

Include at least one file known to trigger aggressive pruning.

## 5. Procedure

1. Run strict enforcement on corpus with fixed settings.
2. Capture per-attack note counts before and after pruning.
3. Verify resulting note-offs match retained note-ons.
4. Compare musical continuity across phrase boundaries.
5. Re-run to confirm deterministic output.

## 6. Acceptance Criteria
Pass for a file requires:

1. no runtime failure
2. no malformed note pairing
3. pruning behavior consistent with rule definition
4. no catastrophic phrase collapse unless documented as expected

Study pass requires stable behavior across corpus and documented rule-consistent outputs.
